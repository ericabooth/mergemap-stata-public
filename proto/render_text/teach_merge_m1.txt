row paired (or not) with its key match in using

  master: work (in memory)              using: county_key.dta
  key: county (duplicates ok)           key: county (unique)
  +------------------------+          +------------------------+
  | county   wage          |          | county   cname         |
  | Bell     12.10         |          | Bell     Bell Cty      |
  | Bell     14.75         |          | Coke     Coke Cty      |
  | Coke      9.30         |          | Duval    Duval Cty     |
  | Hays     11.20         |          +------------------------+
  +------------------------+
        |
        |  merge m:1 county, keep(1 3)
        v
  result: work (4 rows)
  +--------------------------------------------------+
  | county   wage    cname      _merge               |
  | Bell     12.10   Bell Cty   3       matched      |
  | Bell     14.75   Bell Cty   3       matched      |
  | Coke      9.30   Coke Cty   3       matched      |
  | Hays     11.20   .          1       master-only  |  <- kept; cname padded with missing
  |( Duval   .       Duval Cty  2       using-only ) |  <- dropped by keep(1 3)
  +--------------------------------------------------+
  size rule: rows(result) = matched + master-only        4 = 3 + 1
